## 🏆 About Kriti

**Kriti** is the annual inter-hostel technical competition organized by **IIT Guwahati** — one of the most competitive and prestigious intra-college tech tournaments in the institute. Students from different hostels compete across multiple problem statements spanning domains like game development, web dev, machine learning, and more.

**Gamedev PS** is one of the most creative and demanding problem statements in Kriti — teams are tasked with designing and building a playable game from scratch within the competition timeline.

---

## 🎮 About This Project

This repository contains **Lohit Hostel's entry** for the **Gamedev Problem Statement at Kriti 2025**.

The project is **incomplete** — the codebase has missing parts and was not fully finished within the competition period. However, significant effort went into the **game design, art direction, and asset creation** side of the project.

The assets, visuals, and creative direction represent the team's work and are preserved here as a record of what was built.

---

## ✨ What Was Built

- 🎨 **Game art and visual assets** — custom designed sprites, UI elements, and environment artwork
- 🗺️ **Level/scene design** — layout and world-building for the game environment
- 🧩 **Partial game logic** — core mechanics partially implemented in code
- 🎭 **Character and object assets** — designed from scratch for the game's theme

---

## ⚠️ Project Status

This project is **not actively maintained** and is **not planned for future updates**.

The repository is preserved as-is to document the team's work during Kriti 2025. The incomplete code sections were a result of time constraints during the competition — the creative and design work, however, was completed to a high standard.

## 🚀 Running the Project

> ⚠️ Note: The project is incomplete and may not run fully without errors.

If you'd like to explore what was built:

1. Install **Unity Hub** and open the `LohitKritiGame25` folder as a Unity project
2. Browse the `Assets/` folder to view scenes, scripts, and art assets
3. Some scenes may load partially — code gaps exist in the logic layer
